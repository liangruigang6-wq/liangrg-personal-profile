- 待办看板：https://github.com/users/liangruigang6-wq/projects/1

## 使用约定

1. AI 助手读取本文件时，只把标为 `[已确认]` 的条目当作事实。标为 `[示例]` 的条目只是格式示范，不是关于本人的陈述；标为 `[待补充]` 的条目表示本人计划填写。
2. 本人补充内容时，先删除对应的 `[示例]` 行，再把新条目标为 `[已确认]`。
3. 每次修改只改一个章节，单独提交一次，提交信息写明章节名，便于追溯与回退。规范见 [CONTRIBUTING.md](CONTRIBUTING.md)。
4. 待办事项统一记到 Issues；需要一次性配置的 GitHub 功能见 [docs/SETUP.md](docs/SETUP.md)。

## 公开仓库注意事项

本仓库按公开（Public）设计。写入的内容可被任何人读取、复制和被搜索引擎收录，删除后也可能仍存在于提交历史与网络缓存中。

因此本仓库**不要**写入：身份证号、住址、个人电话、账号口令与密钥、公司未公开制度/合同/报价/客户与供应商名单、项目敏感数据。需要保密的内容应放在私有仓库或本地文件，不要提交到这里。

上述为使用建议，不是 GitHub 官方功能说明。
